# Ассеты карусели (`Karusel/assets/carousel`)

## Обязательно в репозитории

- `brand/colors.json` — зеркало/токены цветов (см. `Karusel/docs/figma-workflow.md`).

## Опционально (после экспорта из Figma)

- `brand/logo.png` — путь задаётся в JSON токенах (`assets.logo`); без файла билдер работает без логотипа.
- `icons/*.png` — иконки для слайдов (например «Кому полезно»); см. `Karusel/README.md`.
- `decorations/*` — дополнительные декоративные изображения при необходимости.

Папки `icons/` и `decorations/` можно создать локально; они не обязаны быть в git.
