# Навигация бота Karusel — дерево шагов и кнопок

Структура повторяет пошаговый сценарий создания карусели (как в КОНТЕНТ МАШИНА).

---

## Дерево навигации

```
/start
│
├── [Reply под полем ввода]  Главная  ────────────────────►  Главное меню
│
├── [Inline]  Карусель  ──────────────────────────────────►  Шаг 1. Режим генерации
│
└── /carousel  ────────────────────────────────────────────►  Шаг 1

══════════════════════════════════════════════════════════════════════════════
Шаг 1. Режим генерации
══════════════════════════════════════════════════════════════════════════════
│
├── [Inline]  С персонажем   ─────────────────────────────►  Шаг 2 (нужны фото)
├── [Inline]  Без персонажа  ─────────────────────────────►  Шаг 2 (фото опциональны)
└── [Inline]  Назад          ─────────────────────────────►  Главное меню

══════════════════════════════════════════════════════════════════════════════
Шаг 2. Фото
══════════════════════════════════════════════════════════════════════════════
│
├── Пользователь присылает фото
│   └── Ответ: «Фото получено» + [Перейти к настройкам] [Изменить фото] [Назад]
│
├── [Inline]  Перейти к настройкам  ───────────────────────►  Шаг 3. Настройки
├── [Inline]  Изменить фото        ───────────────────────►  Сброс фото, снова Шаг 2
└── [Inline]  Назад                ───────────────────────►  Шаг 1

  В режиме «Без персонажа»: сразу есть [Перейти к настройкам] без фото.

══════════════════════════════════════════════════════════════════════════════
Шаг 3. Настройки карусели
══════════════════════════════════════════════════════════════════════════════
│
├── [Inline]  Перейти к сценарию  ───────────────────────►  Шаг 4. Сценарий
└── [Inline]  Назад                ───────────────────────►  Шаг 2

══════════════════════════════════════════════════════════════════════════════
Шаг 4. Сценарий
══════════════════════════════════════════════════════════════════════════════
│
├── [Inline]  Ввести текст  ──────────────────────────────►  Подсказка «Напиши сценарий…»
├── Пользователь присылает текст (ТЗ)
│   └── Запуск пайплайна → Готово
└── [Inline]  Назад                ───────────────────────►  Шаг 3

══════════════════════════════════════════════════════════════════════════════
Готово (после генерации)
══════════════════════════════════════════════════════════════════════════════
│
├── [Inline]  Новая карусель  ────────────────────────────►  Шаг 1
└── [Inline]  Назад                ───────────────────────►  Главное меню
```

---

## Кнопка «Назад» по шагам

| Текущий шаг | Назад ведёт на |
|-------------|----------------|
| Шаг 1       | Главное меню   |
| Шаг 2       | Шаг 1          |
| Шаг 3       | Шаг 2          |
| Шаг 4       | Шаг 3          |

---

## Типы клавиатур

- **Reply** — одна кнопка **«Главная»** под полем ввода, показывается после `/start`, действует на любом шаге.
- **Inline** — под сообщением на каждом шаге: свои действия + **«Назад»** (кроме главного меню).

---

## Callback-данные (для разработки)

| Callback       | Действие                    |
|----------------|-----------------------------|
| `car:enter`    | Вход в карусель → Шаг 1     |
| `car:back_0`   | Назад в главное меню        |
| `car:back_1`   | Назад на Шаг 1              |
| `car:back_2`   | Назад на Шаг 2              |
| `car:back_3`   | Назад на Шаг 3              |
| `car:mode_with`    | Режим «С персонажем»   |
| `car:mode_without` | Режим «Без персонажа» |
| `car:to_settings`  | Шаг 2 → Шаг 3           |
| `car:change_photo` | Сброс фото, снова Шаг 2 |
| `car:to_scenario`  | Шаг 3 → Шаг 4           |
| `car:scenario_text`| Подсказка ввести текст   |
