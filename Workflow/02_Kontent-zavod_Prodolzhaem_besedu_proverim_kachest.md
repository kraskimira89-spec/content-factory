## Команды и пути для SD

### Запуск SD WebUI (AUTOMATIC1111)

Раздел «Этап 1. Стабилизация и тест SD» в `passport-project.md` можно дописать так:

- Путь к WebUI:
`D:\AI\stable-diffusion-webui`.[^1]
- Базовый запуск (из PowerShell / CMD):

```bat
cd /d D:\AI\stable-diffusion-webui
webui-user.bat
```

- Вариант с флагами под 12 GB VRAM:

```bat
set COMMANDLINE_ARGS=--xformers --medvram --opt-sdp-attention
webui-user.bat
```

- Адрес интерфейса после запуска:
`http://127.0.0.1:7860`.[^2]


### Тестовый прогон SD 1.5

В чек‑лист Этапа 1 добавь пункты:

- Убедиться, что модель `v1-5-pruned-emaonly.safetensors` лежит в
`D:\AI\stable-diffusion-webui\models\Stable-diffusion`.[^2]
- В WebUI выбрать эту модель и сгенерировать 3 картинки 512×512: кот, человек, предмет (CFG 7, 20–25 шагов, Euler a или DPM++ 2M Karras — на твой вкус).[^1][^2]


## Команды и пути для Ollama

Раздел «Этап 2. Подключение Ollama» в `passport-project.md` можно расширить так.

### Установка Ollama (Windows)

(Предполагаю стандартный путь, поправим по факту.)

- Скачать инсталлер с `https://ollama.com/download/windows` и установить в `C:\Program Files\Ollama\` (по умолчанию).[^1]
- После установки перезайти в систему (чтобы PATH подтянулся).[^1]


### Проверка, что Ollama видит GPU

```bat
ollama run llama3:latest
```

Параллельно в отдельном окне:

```bat
nvidia-smi
```

- В `nvidia-smi` должно быть видно процесс `ollama` или `ollama.exe` с загрузкой GPU/VRAM.[^2][^1]


### Загрузка и запуск модели (пример DeepSeek)

```bat
ollama pull deepseek-r1:8b
ollama run deepseek-r1:8b
```

Для быстрого теста:

## Черновик раздела «Чек‑лист перед запуском SD/LLM»

Предлагаю добавить в оба паспорта общий раздел (или вынести в отдельный `checklist.md`):

### Чек‑лист перед запуском SD

1. **Охлаждение и питание**
    - MSI Afterburner запущен, профиль андервольта/разгона загружен.[^2]
    - Температурный лимит ~75 °C, Power Limit 95%, вентиляторы не в «тихом» режиме.[^2]
    - В комнате нет экстремальной жары, корпус не забит пылью (визуальная проверка).
2. **Система**
    - Нет тяжёлых задач в фоне (игры, рендер, кодировка видео).
    - Ноут/ПК подключён к ИБП или стабильной сети (желательно).
    - Свободно не меньше 10–15 GB RAM (проверка через Диспетчер задач).
3. **SD/WebUI**
    - Путь к проекту: `D:\AI\stable-diffusion-webui`.[^1][^2]
    - В `webui-user.bat` прописаны актуальные `COMMANDLINE_ARGS` (`--medvram`, `--opt-sdp-attention`, при необходимости `--xformers`).[^1]
    - Модель SD 1.5 (`v1-5-pruned-emaonly.safetensors`) на месте, SDXL временно отключены, если тестируем только SD 1.5.[^2][^1]
4. **Тест перед длинной сессией**
    - Прогнать один короткий job 512×512 и убедиться, что температура/VRAM в норме.
    - Сохранить путь к результату и зафиксировать время генерации (для метрик).[^1]

### Чек‑лист перед запуском LLM (Ollama)

1. **GPU/VRAM**
    - SD/игры закрыты, если планируется тяжёлый LLM (8–14B).
    - `nvidia-smi` не показывает других нагружающих процессов на GPU.[^2][^1]
2. **Ollama**
    - Сервис Ollama запущен (если не служба, то просто выполнить `ollama run llama3:latest` как смоук‑тест).[^1]
    - Нужные модели уже скачаны (`ollama list` для проверки).[^1]
3. **Сессия**
    - Для длительного диалога использовать простой терминал / клиент без лишних плюшек, чтобы не было вылетов.
    - При первых запусках смотреть на `nvidia-smi` и загрузку CPU, чтобы убедиться, что всё в пределах разумного.[^2][^1]
