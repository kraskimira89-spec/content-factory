# Content Factory — Шаблоны страниц

Плагин добавляет в админке WordPress подменю **«Страницы → Шаблоны страниц»**: таблица выбора шаблонов и редактирование каждого шаблона блоками (Gutenberg).

## Установка

1. Скопируйте папку `content-factory-page-templates` в каталог плагинов WordPress:
   - **Локально:** `www\entuziastov75.ru\wp-content\plugins\`
   - **На VPS:** после деплоя путь тот же: `wp-content/plugins/`
2. В админке: **Плагины → Установленные** — найдите «Content Factory — Шаблоны страниц» и нажмите **Активировать**.

## Использование

- В меню **Страницы** появится пункт **Шаблоны страниц**.
- Открытие пункта показывает таблицу шаблонов (создание, удаление, список).
- Редактирование шаблона открывает блочный редактор (Gutenberg); настройка выполняется блоками вручную.
