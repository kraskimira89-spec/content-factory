# Design — работа с дизайном и Figma

Отдельная зона для задач по дизайну: макеты Figma, дизайн-система, связь дизайн → код.

## Содержимое

| Файл / папка | Назначение |
|--------------|------------|
| [figma-rules.md](figma-rules.md) | Правила работы с Figma: URL, контекст, реализация в коде |
| [konferenc-zal-figma.md](konferenc-zal-figma.md) | Макет и «живая» спецификация лендинга конференц-зала |
| **Design-main/** | React-проект из Figma Make — эталон лендинга; `npm run dev` → http://localhost:5173/ |
| README.md | Этот файл |

## Агент по дизайну

При работе в этой папке или при запросах про Figma/дизайн используется контекст агента по дизайну (см. `.cursor/rules/design-agent.mdc`):

- Получение контекста из Figma по URL (file key + node-id)
- Реализация макетов в коде с сохранением визуального соответствия
- Code Connect (связь компонентов Figma с кодом)
- Правила дизайн-системы проекта

## Связь с проектом

- **Сайт (VPS):** тема `entuziastov75-child` — CSS, компоненты, стили
- **Контракт:** цвета, типографика, отступы можно фиксировать в `design/tokens.md` (при появлении)
