# Форматы FAQ в проекте

Сводка форматов FAQ в .md-файлах и их поддержка парсером `scripts/faq_parser.py`.

---

## 1. Шаблон для REST API

**Файл:** `prompts/templates/service_page.md` (в секции service_data_fields)

**Формат:** JSON для `service_data` / REST API

```json
[
  {"q": "Сколько сеансов нужно?", "a": "8–12 для устойчивого результата."},
  {"q": "Можно с детьми?", "a": "Да, с 6 лет с родителем."}
]
```

| Поле   | Ключ | Тип                    |
|--------|------|------------------------|
| Вопросы-ответы | `faq` | `array<object>` |

Целевой формат для записи в `wp_options` и вывода в шаблоне темы.

**Парсер:** ✅ Поддерживается (поиск JSON в блоке FAQ)

---

## 2. Ручные страницы (`materials/pages_manual/`)

**Файлы:** `materials/pages_manual/pressoterapiya.md`, `materials/pages_manual/solyanaya-komnata.md`

**Формат эталон:** вопрос жирным, ответ — следующим абзацем

```markdown
## Часто задаваемые вопросы

**Больно ли делать прессотерапию?**

Нет, процедура безболезненна и не травмирует кожу.
```

**Формат со span (оранжевые вопросы):**

```markdown
<span style="color:#ff8800">**Больно ли делать прессотерапию?**</span>

Нет, процедура безболезненна и не травмирует кожу.
```

**Парсер:** ✅ Поддерживается полностью (эталон + span)

**Дублирование:** Agent 4 при публикации страницы услуги удаляет блок FAQ из `post_content` — FAQ выводится только шаблонным аккордеоном из `service_data`. Контент в .md сохраняется для парсера и правок.

---

## 3. Draft-файлы (`docs/services/*-draft.md`)

**Формат:** только нумерованный список вопросов

```markdown
## Блок 8. FAQ

### 8.1. Вопросы

1. Чем кедровая бочка отличается от обычной бани и сауны?
2. Больно ли находиться в фитобочке?
3. Помогает ли кедровая бочка при похудении и целлюлите?
```

Ответов нет.

**Парсер:** ❌ Не поддерживается (нет ответов для REST API)

---

## 4. ТЗ продающих страниц (`docs/services/*-selling-tz.md`)

**Формат:** только нумерованные вопросы

```markdown
### 2.9. FAQ (частые вопросы)
1. Чем фитобочка отличается от бани и сауны?
2. Помогает ли кедровая бочка при похудении и целлюлите?
3. Сколько сеансов нужно для видимого результата?
```

**Парсер:** ❌ Не поддерживается (нет ответов)

## Сводная таблица

| Источник | Формат | Ответы | Парсер |
|----------|--------|--------|--------|
| `prompts/templates/service_page.md` | `[{"q":"...","a":"..."}]` | ✅ | ✅ |
| `materials/pages_manual/*.md` | `**Вопрос?**` или `<span>**Вопрос?**</span>` + абзац | ✅ | ✅ |
| `docs/services/*-draft.md` | `## Блок 8. FAQ` + нумерованные вопросы | ❌ | ❌ |
| `docs/services/*-selling-tz.md` | `### 2.9. FAQ` + нумерованные вопросы | ❌ | ❌ |

---

## Использование парсера

```bash
# Вывести FAQ в JSON
python scripts/faq_parser.py materials/pages_manual/pressoterapiya.md
```

При запуске **Agent 7** FAQ автоматически парсится из ручного файла и отправляется в REST API (`/wp-json/entuziastov75/v1/service-data/{slug}`).
