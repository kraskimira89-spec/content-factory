# Шаблон лендинга «Конференц-зал» — эталонная структура

**Цель:** заменить стандартный шаблон страницы Услуги на специализированный лендинг аренды зала.

**Страница:** http://91.229.11.147/services/konferenc-zal/

**Источник:** анализ лучших лендингов аренды залов и коворкингов.

**Роль:** эталонный образец для шаблона страниц Сервисов. Общий шаблон: `docs/services-landing-template.md`.

**Контент‑завод:** собрана база — страница WP, md‑шаблон, JSON под несколько ЦА. Можно генерировать варианты текстов, не трогая вёрстку. Дальше — скрипт/агент: JSON → новая версия под ЦА → комплект текстов для вставки в WP.

## 1. Базовая структура (порядок блоков)

| # | Блок | Назначение |
|---|------|------------|
| 1 | Hero (первый экран) | УТП, цена «от», кнопки |
| 2 | Для кого / под какие мероприятия | Сценарии использования |
| 3 | Преимущества площадки | 3–6 пунктов |
| 4 | Описание зала (характеристики) | Метраж, вместимость, адрес |
| 5 | Оснащение | Оборудование список |
| 6 | Тарифы и почасовая аренда | Пакеты: час, 4 часа, день |
| 7 | Бронирование | Форма, заявка, телефон |
| 8 | Фото-галерея | 5–10 фото с подписями |
| 9 | Отзывы и кейсы | Социальное доказательство |
| 10 | Как добраться / карта / парковка | Локация |
| 11 | FAQ | Ответы на вопросы |
| 12 | Финальный CTA | Оффер + форма |
