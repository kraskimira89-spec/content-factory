# Настройка выпадающего меню «Сервисы»

**Цель:** в меню «Сервисы» три пункта зала отображаются как дочерние:

```
Сервисы
  ├── Зал для тренингов
  ├── Зал для Онлайн-школ и вебинаров
  └── Зал для Коучей и консультантов
```

---

## 1. Русские названия страниц

После выполнения `python scripts/publish_konferenc_zal.py` заголовки страниц (post_title) установлены как:

| Slug | Название в меню |
|------|------------------|
| korporativnye-treningi | Зал для тренингов |
| onlajn-shkoly | Зал для Онлайн-школ и вебинаров |
| kouchting | Зал для Коучей и консультантов |

Страницы создаются как дочерние страницы «Сервисы» (parent_slug: services). При добавлении в меню WordPress использует их заголовок как подпись.

---

## 2. Добавление в меню WordPress

1. **Войти:** wp-admin → Внешний вид → Меню.

2. **Выбрать меню** «Сервисы».

3. **Добавить страницы:**
   - Слева: «Страницы» → «Все страницы».
   - Найти и отметить:
     - «Зал для тренингов»
     - «Зал для Онлайн-школ и вебинаров»
     - «Зал для Коучей и консультантов»
   - Нажать «Добавить в меню».

4. **Расставить иерархию:**
   - Перетащить эти 3 пункта так, чтобы они были под «Сервисы» (с отступом).
   - В итоге:
     ```
     Сервисы
       ├── Зал для тренингов
       ├── Зал для Онлайн-школ и вебинаров
       └── Зал для Коучей и консультантов
     ```

5. **Сохранить меню.**

---

## 3. Конфигурация в content-factory

Названия и родитель заданы в `config/shared-config.json` → `konferenc_zal_pages`:

```json
"korporativnye-treningi": { "parent_slug": "services", "menu_title": "Зал для тренингов", ... },
"onlajn-shkoly":          { "parent_slug": "services", "menu_title": "Зал для Онлайн-школ и вебинаров", ... },
"kouchting":              { "parent_slug": "services", "menu_title": "Зал для Коучей и консультантов", ... }
```

При публикации через `publish_konferenc_zal.py` страницы создаются под `services`, заголовки обновляются.

---

## 4. Шаблон страницы WordPress

Если главная страница Конференц-зала использует особый шаблон (например, `page-landing.php`), задайте его в `config/shared-config.json`:

```json
"konferenc_zal_pages": {
  "_page_template": "page-landing.php",
  ...
}
```

Тогда при публикации этот шаблон будет применён ко всем трём страницам. Пустое значение — шаблон по умолчанию.
