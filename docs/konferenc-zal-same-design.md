# Одинаковое оформление страниц залов с главной Конференц-зал

Чтобы страницы **Зал для тренингов**, **Зал для Онлайн-школ и вебинаров**, **Зал для Коучей и консультантов** выглядели так же, как главная [Конференц-зал](http://91.229.11.147/services/konferenc-zal/) (hero, блок «Как проходит сеанс», «Результаты курса», таблицы, FAQ), нужно два условия.

---

## 1. Service_data на VPS — сделано

Для каждого из трёх slug на VPS отправлены данные:

- **results** — «Результаты курса» (галочки)
- **comparison** — таблица «Почему в Энтузиасте?»
- **faq** — блок «Часто задаваемые вопросы»
- **steps** — «Как проходит сеанс» (шаги)
- **indications** — «Показания к применению»
- **pricing** — таблица «Стоимость»

Команды уже выполнялись:
```bash
python scripts/deploy_to_vps.py --mode rest --slug korporativnye-treningi
python scripts/deploy_to_vps.py --mode rest --slug onlajn-shkoly
python scripts/deploy_to_vps.py --mode rest --slug kouchting
```

Тема на VPS подставляет эти данные в блоки страницы по slug.

---

## 2. Шаблон «Лендинг Конференц-зал» и контент страницы

Шаблон выводит:
- контент из редактора страницы (блоки «Для кого», «Преимущества», «Характеристики», «Тарифы», FAQ и т.д.) — **если он есть**;
- плюс захардкоженные блоки шаблона (Hero, галерея, оснащение, рассадки, калькулятор, отзывы и т.д.).

Для страниц «Зал для тренингов», «Зал для Онлайн-школ», «Зал для Коучей» важны блоки из редактора — они выводятся сразу после Hero.

---

## 3. Один и тот же шаблон страницы WordPress

Главная Конференц-зал использует **шаблон страницы** темы (например, «Страница услуги» или «Landing»), который выводит hero, «Как проходит сеанс», «Результаты», таблицы и FAQ из service_data.

**Что сделать вручную:**

1. Войти в **wp-admin** → **Страницы**.
2. Открыть страницу **Конференц-зал** → справа блок **«Атрибуты страницы»** / **«Page Attributes»** → поле **«Шаблон»** / **«Template»**. Запомнить название (например, `Страница услуги` или имя файла вроде `page-service.php`).
3. Для каждой из трёх страниц:
   - **Зал для тренингов**
   - **Зал для Онлайн-школ и вебинаров**
   - **Зал для Коучей и консультантов**  
   открыть редактирование → в **«Шаблон»** выбрать **тот же шаблон**, что у Конференц-зала → **Обновить**.

После этого тема будет рисовать для этих страниц те же блоки (hero, шаги, результаты, таблицы, FAQ), подставляя данные из service_data по slug.

---

## 4. (Опционально) Шаблон через конфиг и скрипт

Если известен **технический идентификатор шаблона** (например, `page-service.php`), его можно задать в `config/shared-config.json`:

```json
"konferenc_zal_pages": {
  "_page_template": "page-service.php",
  ...
}
```

После этого при следующем запуске:

```bash
python scripts/publish_konferenc_zal.py
```

скрипт при обновлении этих страниц передаст в API поле `template`, и шаблон будет установлен автоматически.

## 5. Фото и миниатюры

Как на главной Конференц-зал, для красивого вида нужны:

- **Миниатюра записи** (1200×630 px) — задаётся в редакторе страницы.
- **Фото в блоке «Как проходит сеанс»** (800×500 px на шаг) — загрузка в «Медиафайлы» и вставка в контент или через настройки темы.
- При необходимости — картинки для блока «С этой услугой сочетаются» (800×600 px).

Их нужно добавить вручную в WordPress для каждой из трёх страниц.
