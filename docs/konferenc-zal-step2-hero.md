## 3. Пошаговые действия в WordPress

1. **Войти:** Админка WordPress → Страницы → найти «Конференц-зал» → Редактировать.
2. **Очистить/заменить** первый экран, если там старый контент.
3. **Добавить блоки:**
   - Блок «Заголовок» → уровень H1 → вставить заголовок.
   - Блок «Абзац» → вставить подзаголовок.
   - Блок «Абзац» → вставить строку «От 500 ₽/час · до 40 человек · центр «Энтузиаст»» (при необходимости уменьшить размер шрифта через «Дополнительные настройки»).
   - Блок «Кнопки» или две «Кнопки»:
     - Кнопка 1: «Забронировать время» → ссылка `#bron` или `tel:+79044759101`.
     - Кнопка 2: «Задать вопрос в WhatsApp/Telegram» → ссылка мессенджера.
4. **Фон секции:** В настройках первого блока/группы: Фон → Изображение → загрузить фото зала (рекомендуемый размер 1200×630 px, 16:9).
5. **Якорь формы:** У секции с формой бронирования задать CSS ID `bron`, чтобы кнопка «Забронировать время» прокручивала к ней.
