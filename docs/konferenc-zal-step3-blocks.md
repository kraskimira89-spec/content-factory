# Шаг 3: Блоки «Для кого» и «Преимущества» — Конференц-зал

**Страница:** WordPress → Страницы → Конференц-зал → Редактировать  
**Расположение:** сразу после первого экрана (Hero)

---

## 1. Блок «Для каких мероприятий подходит наш конференц‑зал»

### Заголовок (H2)
```
Для каких мероприятий подходит наш конференц‑зал
```

### Подзаголовок (опционально)
```
Собираете людей в офлайне или ведёте онлайн‑трансляции — пространство уже готово под ваши задачи.
```

### Карточки (5 шт.)

| Заголовок | Описание |
|-----------|----------|
| **Тренинги и мастер‑классы** | Проводите обучение команд и клиентов в зале, где есть всё: от стульев до проектора и звука. |
| **Стратегические сессии и планёрки** | Отдельное пространство для фокусной работы команды, без отвлекающих факторов офиса. |
| **Вебинары и онлайн‑конференции** | Компьютеры, микрофоны, наушники и экран — удобно для Zoom, Teams и других платформ. |
| **Переговоры с партнёрами и инвесторами** | Деловая атмосфера и техника для презентаций — вы показываете уровень ещё до начала встречи. |
| **Запись онлайн‑курсов и образовательного контента** | Тихое пространство, оборудование и экран — можно записывать уроки и обучающие программы. |

### Реализация в Gutenberg
1. Блок «Заголовок» (H2) → заголовок блока
2. Блок «Абзац» → подзаголовок
3. Вариант **А:** блок «Колонки» (2–3 колонки) → в каждой: Заголовок H3 + Абзац  
4. Вариант **Б:** блок «Список» → пункты с заголовком (жирный) + описание

## 2. Блок «Почему организаторам удобно проводить мероприятия у нас»

### Заголовок (H2)
```
Почему организаторам удобно проводить мероприятия у нас
```

### Карточки‑преимущества (5 шт.)

| Заголовок | Описание |
|-----------|----------|
| **Готовая техника «под ключ»** | Экран, проектор, компьютеры, колонки, микрофоны и наушники — приезжаете и сразу начинаете, без проволочек с настройкой. |
| **Гибкая рассадка и 72 м² пространства** | Можно устроить «театр», класс, круглый стол или U‑форму — под формат вашего мероприятия. |
| **Профессиональная атмосфера** | Участники попадают в настроенный под работу зал, а не в случайный офис или коворкинг. |
| **Поддержка на старте** | Поможем подключить презентацию, проверить звук и подготовить зал к началу встречи. |
| **Выгодная почасовая аренда** | Платите только за фактическое время, удобные пакеты «полдня» и «день» для длинных сессий. |

### Реализация в Gutenberg
1. Блок «Заголовок» (H2) → заголовок
2. Блок «Колонки» или «Список» — аналогично блоку «Для кого»
3. Каждое преимущество: короткий заголовок (H3/жирный) + текст

---

## 3. Рекомендация: блок «Как проходит аренда» (опционально)

Добавить сразу после «Преимуществ» для логики «как мы работаем»:

1. **Оставляете заявку** — по форме, телефону или мессенджеру  
2. **Подтверждаем время** — отвечаем и уточняем детали  
3. **Готовим зал** — расставляем мебель под ваш формат  
4. **Проводите мероприятие** — техподдержка на месте
