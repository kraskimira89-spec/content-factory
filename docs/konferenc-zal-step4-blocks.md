# Шаг 4: Блоки «Характеристики», «Оснащение», «Тарифы» — Конференц-зал

**Страница:** WordPress → Страницы → Конференц-зал → Редактировать  
**Расположение:** после блока «Преимущества» (или «Как проходит аренда»)

---

## 1. Блок «Характеристики конференц‑зала»

### Заголовок (H2)
```
Характеристики конференц‑зала
```

### Список параметров

- **Площадь:** 72 м²
- **Вместимость:** до 40 человек
- **Варианты рассадки:** «театр», «класс», «U‑образная», «круглый стол»
- **Формат аренды:** почасовая, пакеты «полдня» и «день»
- **Расположение:** центр «Энтузиаст», г. Ноябрьск *(уточнить адрес)*
- **Время работы:** по предварительному бронированию *(уточнить часы, напр. 10:00–21:00)*

### Вариант — таблица (2 колонки)

| Параметр | Значение |
|----------|----------|
| Площадь | 72 м² |
| Вместимость | до 40 человек |
| Варианты рассадки | «театр», «класс», «U‑образная», «круглый стол» |
| Формат аренды | Почасовая, пакеты «полдня» и «день» |
| Расположение | Центр «Энтузиаст», г. Ноябрьск |
| Время работы | По предварительному бронированию |

### Реализация в Gutenberg
1. Блок «Заголовок» (H2) → «Характеристики конференц‑зала»
2. Блок «Список» (List) — пункты выше  
   **или** блок «Таблица» (Table) — колонки «Параметр» / «Значение»

## 2. Блок «Оснащение конференц‑зала»

### Заголовок (H2)
```
Оснащение конференц‑зала
```

### Список оборудования

1. Проектор и экран для презентаций
2. Компьютеры *(указать кол-во: для спикера, для участников)*
3. Звуковая система и колонки
4. Микрофоны (ручные / петличные)
5. Наушники (для онлайн‑участников, записи, прослушивания)
6. Высокоскоростной интернет (Wi‑Fi)
7. Столы и стулья с возможностью перестановки
8. Флипчарт / маркеры / расходные материалы
9. Удлинители и розетки у столов

### Опционально: подзаголовки H3
- **Видео:** проектор, экран, компьютеры
- **Звук:** колонки, микрофоны, наушники
- **Рабочие места:** столы, стулья, флипчарт, розетки

### Реализация в Gutenberg
1. Блок «Заголовок» (H2) → «Оснащение конференц‑зала»
2. Блок «Список» (List) — пункты выше

## 3. Блок «Тарифы на аренду конференц‑зала»

### Заголовок (H2)
```
Тарифы на аренду конференц‑зала
```

### Подзаголовок (опционально)
```
Выбирайте формат под своё мероприятие — платите только за фактическое время.
```

### Тарифы (примерные значения — уточнить)

| Тариф | Описание | Стоимость |
|-------|----------|-----------|
| **Почасовая аренда** | Минимальное бронирование — 1 час | От 500 ₽/час |
| **Полдня** | 4 часа — выгодный пакет | ___ ₽ (экономия по сравнению с почасовой) |
| **Целый день** | 8 часов, базовое техсопровождение | ___ ₽ |

### Текст под тарифами
```
Точную стоимость и доступность даты можно уточнить по телефону +7 (904) 475-91-01 или через форму ниже.
```

### Кнопка
**«Уточнить стоимость и свободное время»** → ссылка `#bron` (якорь на форму)

### Вариант — карточки (3 колонки)

**Колонка 1 — Почасовая аренда**
> От 500 ₽/час, минимальное бронирование — 1 час.

**Колонка 2 — Полдня**
> 4 часа — ___ ₽ (экономия до ___ ₽ по сравнению с почасовой оплатой).

**Колонка 3 — Целый день**
> 8 часов — ___ ₽, включено базовое техническое сопровождение запуска мероприятия.

### Реализация в Gutenberg
1. Блок «Заголовок» (H2) → «Тарифы на аренду конференц‑зала»
2. Блок «Абзац» → подзаголовок
3. Вариант **А:** блок «Таблица» — колонки «Тариф», «Описание», «Стоимость»
4. Вариант **Б:** блок «Колонки» (3 шт.) — в каждой: заголовок тарифа + описание
5. Блок «Абзац» → текст про уточнение стоимости
6. Блок «Кнопка» → «Уточнить стоимость и свободное время» → `#bron`

---

## 4. Рекомендации

- **Кнопка под тарифами:** обязательна — вести на форму `#bron` (паттерн «посмотрел цены → оставил запрос»).
- **Обновление данных:** все тексты есть в `materials/konferenc-zal-blocks.json` — удобно менять цены, адрес, оснащение и генерировать варианты через LLM.
