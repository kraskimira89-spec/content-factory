## 1. Блок «Как забронировать конференц‑зал»

### Заголовок (H2)
```
Как забронировать конференц‑зал
```

### Шаги (нумерованный список)

1. Оставляете заявку на сайте или пишете нам в мессенджер.
2. Мы уточняем дату, время, формат мероприятия и нужное оборудование.
3. Подтверждаем бронь и готовим зал к вашему приезду.
4. Вы приезжаете в готовое пространство и проводите мероприятие.

### Подпись под списком
```
Обычно подтверждаем бронь в течение 15–30 минут.
```

### Реализация в Gutenberg
1. Блок «Заголовок» (H2)
2. Блок «Список» (List) с нумерацией
3. Блок «Абзац» для подписи

## 2. Блок «Оставить заявку на аренду» (форма) — id="bron"

**Важно:** у секции с формой задать HTML-якорь `bron`, чтобы кнопка Hero прокручивала сюда.

### Заголовок (H2)
```
Оставить заявку на аренду
```

### Подпись
```
Заполните форму — мы свяжемся с вами, уточним детали и подтвердим бронь.
```

### Поля формы (минимальный набор)
- Имя
- Телефон или мессенджер
- Дата и ориентировочное время
- Формат мероприятия (тренинг, сессия, вебинар и т.п.)

### Кнопка
**«Забронировать время»** или **«Уточнить доступность зала»**

### Если формы нет
Временно: блок «Кнопка» с ссылкой `tel:+79044759101` или `https://wa.me/79044759101` + текст «Позвоните или напишите нам».

### Как задать якорь в Gutenberg
1. Выделить блок «Группа» / «Секция», в которую вложена форма
2. Правая панель → «Дополнительные» → «Якорь HTML» → вписать `bron`

## 4. Блок «Отзывы организаторов»

### Заголовок (H2)
```
Отзывы организаторов
```

### Если отзывов пока нет — заглушка
```
Скоро мы добавим отзывы наших клиентов. Оставляйте заявку — и станьте первым!
```

### Пример реального отзыва
**Текст:**
> Проводили стратегическую сессию для команды. Важно было, чтобы всё оборудование работало без сбоев. Зал подготовили заранее, помогли с подключением — начали ровно по расписанию.

**Формат:** Имя/компания (по желанию) + «Задача → как проходило → результат».

### Реализация в Gutenberg
- Вариант **А:** 1–2 карточки с текстом отзывов  
- Вариант **Б:** заглушка до появления отзывов  
- Колонки или список — по желанию

## 5. Блок «Частые вопросы» (FAQ)

### Заголовок (H2)
```
Частые вопросы
```

### Вопросы и ответы (6 шт.)

**1. Можно ли принести свою технику?**  
Да, можно. Сообщите заранее — подготовим розетки и место для подключения.

**2. Помогаете ли с подключением презентации и звука?**  
Да. На старте мероприятия поможем вывести презентацию на экран и проверить звук.

**3. Какая минимальная длительность аренды?**  
Минимум 1 час. Для длительных мероприятий есть выгодные пакеты «полдня» и «день».

**4. Можно ли арендовать зал вечером или в выходные?**  
Да, по предварительному бронированию. Уточните доступность по телефону или через форму.

**5. Как внести предоплату и отменить бронь?**  
Условия предоплаты и отмены обсудим при подтверждении брони.

**6. Можно ли заказать кофе‑брейк?**  
Да, фитобар рядом — чай, кофе и полезные перекусы. Уточните при бронировании.

### Реализация в Gutenberg
- Вариант **А:** блоки «Заголовок» (H3) + «Абзац» на каждый вопрос  
- Вариант **Б:** блок «Аккордеон» / «Спойлер» (если тема поддерживает) — компактнее
