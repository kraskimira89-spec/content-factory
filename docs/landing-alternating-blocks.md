# Чередование блоков лендинга конференц-зала

Страницы генерируются цепочкой агентов 1→9, публикуются через `scripts/publish_konferenc_zal_from_md.py`.

## Порядок блоков

| # | Блок | Вёрстка |
|---|------|--------|
| 1 | Hero | На всю ширину |
| 2 | **Для кого** + **Преимущества** | Два текстовых блока в один ряд (`.landing-row-two-cols`) |
| 3 | Как выглядит зал (галерея) | Фото |
| 4 | Характеристики | Текст слева + фото справа (`.landing-text-image`) |
| 5 | Оснащение | Фото слева + текст справа (`.landing-image-text`) |
| 6 | Тарифы, Как забронировать, форма, кейсы, отзывы, FAQ | Текст по ширине |

## Изображения в блоках «Характеристики» и «Оснащение»

- По умолчанию берётся первое фото галереи для «Характеристики», второе — для «Оснащение» (если в JSON у элементов `gallery` задано поле `image` с URL).
- Опционально в JSON можно задать свои URL:
  - `features_image` — картинка для блока «Характеристики»;
  - `equipment_image` — картинка для блока «Оснащение».

## Стили

Стили для `.landing-row-two-cols`, `.landing-text-image`, `.landing-image-text` добавлены в тему в конец файла `assets/css/landing-pages.css`. На узких экранах блоки переходят в одну колонку.
