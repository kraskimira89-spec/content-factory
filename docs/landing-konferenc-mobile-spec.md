# Мобильная версия лендинга конференц-зала (320–480 px)

Спецификация адаптации секций под экраны 320–480 px. Стили реализованы в теме в `landing-pages.css` (блок `@media (max-width: 480px)`).

## Общие принципы

- Все колонки → 1 колонка (карточки, тарифы, отзывы вертикально).
- Кнопки: 90–95% ширины экрана, высота 44–54 px.
- H1: 28–32 px, H2: 24–28 px, основной текст: 15–16 px.
- Боковые отступы: 16–20 px.
- Отступы между секциями: 60–80 px.
- Касаемые элементы: минимум 44 px по высоте.

## Порядок секций на мобильном

1. Hero (фото + H1 + подзаголовок + цена + 2 кнопки вертикально)
2. For Whom (H2 + карточки в 1 колонку)
3. Benefits (H2 + карточки в 1 колонку)
4. Features (H2 + таблица/список)
5. Pricing (H2 + тарифы в 1 колонку)
6. Equipment (H2 + список в 1 колонку)
7. Booking Steps (H2 + шаги вертикально)
8. Form (H2 + форма, поля и кнопка на всю ширину)
9. Gallery (H2 + фото в 1 колонку)
10. Cases (H2 + карточки кейсов вертикально)
11. Testimonials (H2 + отзывы вертикально)
12. FAQ (H2 + аккордеон, высота строки вопроса 60–70 px)

## Чек-лист проверки

- [ ] Все колонки схлопываются в 1.
- [ ] Кнопки на всю ширину (90–95%), высота 44–54 px.
- [ ] H1: 28–32 px, H2: 24–28 px, текст: 15–16 px.
- [ ] Боковые отступы 16–20 px.
- [ ] Отступы между секциями 60–80 px.
- [ ] Поля формы: высота 48 px, на всю ширину.
- [ ] Галерея: фото вертикально, одно под другим.
- [ ] FAQ: высота строки вопроса 60–70 px.
- [ ] Межстрочный интервал 1.5–1.6.
- [ ] Все кликабельные элементы ≥ 44 px по высоте.

## Где правки

- **Тема (VPS):** `wp-content/themes/entuziastov75-child/assets/css/landing-pages.css` — блок в конце файла `@media (max-width: 480px)`.
