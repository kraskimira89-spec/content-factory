# Скрипт: кнопки, стили, ключи и перелинковка в постах блога

`scripts/add_cta_buttons_to_posts.py` — добавляет в опубликованные посты:
- Кнопки «Далее»/«Записаться»
- Зелёный цвет заголовков (H2–H6)
- Жирное выделение ключевых слов (названия услуг из shared-config)
- Перелинковку: первое упоминание услуги → ссылка на страницу /uslugi/{slug}/

## Использование

```powershell
# Только показать изменения (без правок)
python scripts/add_cta_buttons_to_posts.py --dry-run

# Обновить посты
python scripts/add_cta_buttons_to_posts.py
```

Повторный запуск пропускает посты, в которых уже есть блок кнопок.
