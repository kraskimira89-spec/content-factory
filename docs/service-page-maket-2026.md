# Макет страницы услуги (по Envybox) — реализация

Дата: 2026-03-01

## Что сделано

Макет «Услуги» переработан по [структуре от Envybox](https://envybox.io/blog/struktura-posadochnoj-stranicy/): более воздушный layout, мобайл-фёрст.

### 1. Hero-блок

- **2 колонки (60/40):** слева текст, справа фото
- H1 + подзаголовок (subtitle или краткий intro)
- Маркеры-бейджи: `hero_badges` из данных или авто из `price_time`, `price_five`, `list_left[0]`
- Две кнопки: «Записаться» (primary), «Задать вопрос» (outline)
- На мобиле (<768px): одна колонка, сначала текст, потом фото

### 2. Блок «Для кого эта услуга»

- 3–4 карточки: иконка ✓ + заголовок + текст
- Данные: `audience` (если есть) или `list_left` (показания)
- Сетка: 3 в ряд на десктопе, 1 на мобиле

### 3. Блок «Как проходит процедура»

- Вертикальные шаги с нумерацией (кружок 1–4)
- Каждый шаг: заголовок (до двоеточия) + описание
- Справа (десктоп): место под фото процедуры; на мобиле — под шагами

### 4. Показания и противопоказания

- Без изменений: две колонки, на мобиле — друг под другом

### 5. Стоимость

- Пометка мелким текстом: «Цены могут измениться. Актуальную стоимость уточняйте при записи.»

### 6. FAQ

- Заголовок: «Частые вопросы»
- Аккордеон свёрнут по умолчанию (все закрыты)

### 7. CTA

- Две кнопки: «Записаться», «Получить консультацию»
- Финальный CTA-блок в конце страницы

### 8. Отступы

- Между блоками: 60px (десктоп), 44px (мобиле)
- Контейнер: max-width 1160px для hero, `var(--container)` для остальных

## Файлы

- `entuziastov75-vps`: `template-page-service.php`, `assets/css/service-pages.css`

## Расширение данных

Для блока «Для кого» с полным текстом добавьте в `service_data` массив `audience`:

```php
'audience' => array(
    array( 'title' => 'Хочу похудеть', 'text' => 'Безопасные нагрузки.' ),
    array( 'title' => 'Взрослым 55+', 'text' => 'Деликатный подход.' ),
),
```

Для кастомных маркеров Hero — `hero_badges`:

```php
'hero_badges' => array( '45 мин', 'Курс 10 сеансов', 'От 400 ₽' ),
```
