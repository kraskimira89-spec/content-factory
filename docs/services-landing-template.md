# Шаблон страницы Сервисов — образец для всех страниц меню «Сервисы»

**Назначение:** единая структура лендингов для страниц `/services/*`.  
**Эталон:** Конференц-зал (реализован полностью).  
**Применяется к:** Долголетие, Мастер Клёпа, Прокат, Юридическая помощь, Тренажёрный зал и др.

---

## 1. Универсальная структура блоков

| # | Блок | Обязательный | Конференц-зал | Аренда/Прокат | Услуга/Консультация |
|---|------|---------------|---------------|---------------|----------------------|
| 1 | Hero (первый экран) | ✅ | ✅ | ✅ | ✅ |
| 2 | Для кого / сценарии | ✅ | ✅ | ✅ | ✅ |
| 3 | Преимущества | ✅ | ✅ | ✅ | ✅ |

## 2. Шаблон Hero (первый экран)

**Элементы (всегда):**
- H1 — оффер с ключевыми словами и геолокацией
- Подзаголовок — УТП в 1–2 предложениях
- Строка с ценой «от» (если есть)
- Кнопка основная → `#bron` (якорь на форму)
- Кнопка доп. → WhatsApp/Telegram

**Варианты H1 по типу сервиса:**

| Тип | Пример H1 |
|-----|-----------|
| Аренда | «Конференц‑зал 72 м² в Ноябрьске — почасовая аренда» |
| Прокат | «Прокат [инвентаря] в Ноябрьске — [условия]» |
| Программа | «Долголетие — комплексная программа оздоровления в Ноябрьске» |
| Дети | «Мастер Клёпа — [описание] для детей в Ноябрьске» |
| Консультация | «Юридическая помощь в Ноябрьске — консультации и сопровождение» |

## 4. Форма и якорь #bron

**Все страницы Сервисов:**
- Форма заявки с якорем `id="bron"`
- Кнопка Hero «Забронировать» / «Записаться» → ссылка `#bron`
- Поля формы: Имя, Телефон, [специфичные под сервис]

## 7. Чек-лист при создании новой страницы Сервиса

- [ ] Hero: H1, подзаголовок, цена (если есть), 2 кнопки
- [ ] Блок «Для кого»: 4–5 карточек
- [ ] Блок «Преимущества»: 4–5 пунктов
- [ ] Блок «Характеристики» (если нужен)
- [ ] Блок «Оснащение/что входит» (если нужен)
- [ ] Блок «Тарифы» (если есть цены)
- [ ] Блок «Как оформить»: 4 шага
- [ ] Блок «Форма» с `id="bron"`
- [ ] Блок «Галерея» (если есть фото)
- [ ] Блок «Отзывы» (заглушка или кейсы)
- [ ] Блок «FAQ»: 5–7 вопросов
- [ ] Связка: кнопка Hero → `#bron`
