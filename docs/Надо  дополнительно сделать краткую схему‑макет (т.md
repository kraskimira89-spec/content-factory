# Надо  дополнительно сделать краткую схему‑макет (текстовое описание расположения элементов на первом экране и в 2–3 ключевых секциях), чтобы дизайнер сразу понял визуальный план.

Даю краткую текстовую схему‑макет для дизайнера — как должны располагаться элементы на первом экране и в ключевых секциях.[^1][^2][^3][^4]

***

## Схема‑макет лендинга конференц‑зала

### 1. Первый экран (Hero) — высота 80–100vh

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│  [Фоновое фото зала с затемнением 40–50%]                │
│                                                          │
│                     [Логотип сверху слева]               │
│                     [Меню сверху справа]                 │
│                                                          │
│              ┌─────────────────────────┐                 │
│              │                         │                 │
│              │   H1 (hero.title)       │  ← 40–48px      │
│              │   Крупный, жирный,      │    белый/тёмный│
│              │   2–3 строки макс       │                │
│              │                         │                │
│              │   Подзаголовок          │  ← 18–20px    │
│              │   (hero.subtitle)       │    2–3 строки  │
│              │                         │                │
│              │   [Иконка] От __₽/час  │  ← 16–18px    │
│              │   · до __ человек       │    жирный      │
│              │   · центр "Энтузиастов" │                │
│              │                         │                │
│              │  ┌──────────────────┐   │                │
│              │  │ Забронировать    │   │  ← 50px высота│
│              │  │ зал для сессии   │   │    акцентный  │
│              │  └──────────────────┘   │    цвет        │
│              │                         │                │
│              │  ┌──────────────────┐   │                │
│              │  │ Задать вопрос в  │   │  ← 48px высота│
│              │  │ WhatsApp         │   │    outline     │
│              │  └──────────────────┘   │    или светлее │
│              │                         │                │
│              └─────────────────────────┘                │
│                                                          │
│              [Стрелка вниз для прокрутки]               │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**Важно:**

- Контент по центру (или чуть левее центра).
- Заголовок + подзаголовок + цена + 2 кнопки = весь ключевой оффер виден без прокрутки.
- Кнопки на расстоянии 15–20 px друг от друга.
- Фон: качественное фото зала или градиент бренда.[^2][^3][^4][^1]

### 2. Секция «Для кого» (For Whom)

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│     H2: Для каких мероприятий подходит наш              │
│         конференц‑зал                        ← 32–36px │
│                                                        │
│     Подзаголовок (опционально, 1 строка)     ← 16–18px │
│                                                        │
│  ┌─────────────────┐      ┌─────────────────┐          │
│  │  [Иконка]       │      │  [Иконка]       │          │
│  │                 │      │                 │          │
│  │  Тренинги и     │      │  Стратегические │          │
│  │  мастер‑классы  │      │  сессии         │          │
│  │                 │      │                 │          │
│  │  Проводите      │      │  Отдельное      │          │
│  │  обучение в зале│      │  пространство   │          │
│  │  с готовой      │      │  для фокусной   │          │
│  │  техникой       │      │  работы команды │          │
│  │                 │      │                 │          │
│  └─────────────────┘      └─────────────────┘          │
│                                                        │
│  ┌─────────────────┐      ┌─────────────────┐          │
│  │  [Иконка]       │      │  [Иконка]       │          │
│  │                 │      │                 │          │
│  │  Вебинары и     │      │  Переговоры     │          │
│  │  онлайн‑конф.   │      │  с партнёрами   │          │
│  │  ...            │      │  ...            │          │
│  └─────────────────┘      └─────────────────┘          │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**Важно:**

- H2 по центру, отступ сверху 80 px, снизу 40 px.
- Карточки: 2 колонки на десктопе (или 3, если карточек 6), 1 на мобильном.
- Карточка: белый фон, лёгкая тень `box-shadow: 0 2px 8px rgba(0,0,0,0.08)`, радиус 8 px.
- Иконка (опционально) 48×48 px сверху или слева.
- Заголовок карточки — жирный, 18–20 px.
- Текст — обычный, 15–16 px, 2–3 строки.
- Отступ между карточками: 20–30 px.[^3][^4][^1]

### 3. Секция «Тарифы» (Pricing)

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│     H2: Тарифы на аренду конференц‑зала     ← 32–36px  │
│                                                          │
│     Подзаголовок: Выбирайте формат под      ← 16–18px  │
│     своё мероприятие...                                 │
│                                                          │
│  ┌────────────┐  ┌────────────┐  ┌────────────┐        │
│  │ Почасовая  │  │  Полдня    │  │  Целый день│        │
│  │  аренда    │  │  (4 часа)  │  │  (8 часов) │        │
│  │            │  │            │  │            │        │
│  │  От __₽/ч  │  │   ____ ₽   │  │   ____ ₽   │  ← цена│
│  │            │  │            │  │            │    крупно│
│  │  Минимум   │  │  Экономия  │  │  Включено  │    жирно│
│  │  __ часа   │  │  до __₽    │  │  тех. сопр.│        │
│  │            │  │            │  │            │        │
│  │ ┌────────┐ │  │ ┌────────┐ │  │ ┌────────┐ │        │
│  │ │Забронир│ │  │ │Забронир│ │  │ │Забронир│ │        │
│  │ └────────┘ │  │ └────────┘ │  │ └────────┘ │        │
│  └────────────┘  └────────────┘  └────────────┘        │
│                                                          │
│     Точную стоимость можно уточнить по телефону...     │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**Важно:**

- 3 карточки тарифов в ряд на десктопе, 1 на мобильном.
- Карточка: белый фон, лёгкая тень, радиус 8–12 px.
- Заголовок тарифа — 20–24 px, жирный.
- Цена — самый крупный элемент в карточке (32–40 px), жирный, акцентный цвет.
- Описание — 14–16 px, обычный.
- Кнопка «Забронировать» внизу карточки, 44–48 px высота, акцентный цвет.
- Средний тариф (например, «Полдня») можно визуально выделить: чуть больше карточка, ярче рамка или бейдж «Популярный».[^5][^6][^1][^2]

### 4. Секция «Форма заявки» (Form)

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│     H2: Оставить заявку на аренду           ← 32–36px  │
│                                                          │
│     Заполните форму — мы свяжемся с вами... ← 16–18px  │
│                                                          │
│              ┌────────────────────────┐                 │
│              │                        │                 │
│              │  [Форма в карточке]    │  ← белый фон   │
│              │  с лёгкой тенью        │    или #F9F9F9 │
│              │                        │    радиус 12px │
│              │  ┌──────────────────┐  │                 │
│              │  │ Имя              │  │  ← 48px высота │
│              │  └──────────────────┘  │    поля        │
│              │                        │                 │
│              │  ┌──────────────────┐  │                 │
│              │  │ Телефон/мессенджер│  │                 │
│              │  └──────────────────┘  │                 │
│              │                        │                 │
│              │  ┌──────────────────┐  │                 │
│              │  │ Дата и время     │  │                 │
│              │  └──────────────────┘  │                 │
│              │                        │                 │
│              │  ┌──────────────────┐  │                 │
│              │  │ Формат мероприятия│  │                 │
│              │  └──────────────────┘  │                 │
│              │                        │                 │
│              │  ┌──────────────────┐  │                 │
│              │  │ Забронировать    │  │  ← 54px высота │
│              │  │ время            │  │    акцентный   │
│              │  └──────────────────┘  │    на всю      │
│              │                        │    ширину      │
│              │                        │                 │
│              │  Мы ответим в течение  │  ← мелкий текст│
│              │  __ минут              │    под кнопкой │
│              │                        │                 │
│              └────────────────────────┘                 │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**Важно:**

- Форма в центре, максимальная ширина 500–600 px.
- Карточка формы: белый или светло-серый фон (\#F9F9F9), тень `box-shadow: 0 4px 16px rgba(0,0,0,0.1)`, радиус 12 px.
- Поля: высота 48 px, радиус 6 px, рамка \#DDD, при фокусе — акцентный цвет рамки.
- Лейблы над полями или плейсхолдеры внутри.
- Кнопка отправки: высота 54 px, на всю ширину формы, акцентный цвет, текст белый, жирный.
- Под кнопкой мелкий текст-уверение («Ответим в течение...»).[^7][^1][^2]

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│     H2: Отзывы организаторов                ← 32–36px  │
│                                                          │
│  ┌─────────────────┐  ┌─────────────────┐  ┌──────────┐│
│  │                 │  │                 │  │          ││
│  │ "Мы арендуем... │  │ "Проводили...   │  │ "Отличное││
│  │  зал легко      │  │  важно было...  │  │  пространс││
│  │  трансформи-    │  │  помогли с...   │  │  тво..."  ││
│  │  руется..."     │  │  ровно по..."   │  │          ││
│  │                 │  │                 │  │          ││
│  │  — Центр        │  │  — Имя,         │  │  — Имя,  ││
│  │    «Таганай»    │  │    Компания     │  │    Компан││
│  │    НКО, с 2013  │  │                 │  │          ││
│  │                 │  │                 │  │          ││
│  └─────────────────┘  └─────────────────┘  └──────────┘│
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**Важно:**

- 2–3 карточки в ряд на десктопе, 1 на мобильном.
- Карточка: белый фон, лёгкая тень, радиус 8 px, padding 24–32 px.
- Текст отзыва — курсивом или в кавычках, 15–16 px.
- Автор и компания — внизу карточки, мелким шрифтом (14 px), обычным или полужирным.
- Можно добавить фото/аватар автора слева от имени (опционально).[^8][^9][^10]

### 6. Секция «FAQ»

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│     H2: Частые вопросы                      ← 32–36px  │
│                                                          │
│  ┌────────────────────────────────────────────────────┐ │
│  │  ❓ Можно ли принести свою технику?        [+]    │ │
│  └────────────────────────────────────────────────────┘ │
│                                                          │
│  ┌────────────────────────────────────────────────────┐ │
│  │  ❓ Помогаете ли с подключением...?        [+]    │ │
│  └────────────────────────────────────────────────────┘ │
│                                                          │
│  ┌────────────────────────────────────────────────────┐ │
│  │  ❓ Какая минимальная длительность аренды? [+]    │ │
│  └────────────────────────────────────────────────────┘ │
│                                                          │
│  ┌────────────────────────────────────────────────────┐ │
│  │  ❓ Можно ли арендовать зал вечером?       [–]    │ │
│  │                                                    │ │
│  │     Да, мы работаем по предварительному           │ │
│  │     бронированию с __ до __ часов...              │ │
│  │                                                    │ │
│  └────────────────────────────────────────────────────┘ │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**Важно:**

- Аккордеон (вопросы раскрываются при клике) или просто список вопрос/ответ.
- Вопрос — жирный, 16–18 px, иконка «+» или стрелка справа.
- Ответ — обычный текст, 15–16 px, появляется под вопросом при клике.
- Лёгкая рамка или разделители между пунктами.
- Максимальная ширина блока 800 px для читаемости.[^1][^2][^3]

## Итоговая схема всей страницы (краткий план)

```
1. Hero (фото + заголовок + подзаголовок + цена + 2 кнопки)
   ↓
2. For Whom (H2 + 4–6 карточек 2×3)
   ↓
3. Benefits (H2 + 4–6 карточек 2×3)
   ↓
4. Features (H2 + таблица/карточки характеристик)
   ↓
5. Pricing (H2 + 3 карточки тарифов в ряд)
   ↓
6. Equipment (H2 + список с иконками, 2 колонки)
   ↓
7. Booking Steps (H2 + 4 нумерованные карточки)
   ↓
8. Form (H2 + форма в карточке)
   ↓
9. Gallery (H2 + сетка фото 3 колонки)
   ↓
10. Cases (H2 + карточки кейсов, результат жирным)
   ↓
11. Testimonials (H2 + 2–3 карточки отзывов)
   ↓
12. FAQ (H2 + аккордеон или список)
   ↓
    Footer (контакты, соцсети, копирайт)
```


***

Эта схема даёт дизайнеру полное визуальное представление о расположении элементов, размерах, отступах и логике секций.[^4][^2][^3][^1]

Если нужно, могу дополнительно описать мобильную версию (как карточки схлопываются в 1 колонку, как кнопки становятся на всю ширину и т.п.).
