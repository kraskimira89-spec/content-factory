## 3. Чек‑лист при настройке новой услуги

### 3.1. Фиксация эталона

- [ ] Выбрать актуальный .md (или сгенерировать первым прогоном)
- [ ] Создать `materials/etalon_{slug}_structure.md` по аналогии с `etalon_suv_structure.md`
- [ ] Зафиксировать: текущая структура, матрица блоков, целевые H2, недостающие блоки

### 3.2. Специфика процедуры (в `brand_voice.md`)

- [ ] Добавить блок «Точность по услугам» для {услуга}:
  - краткое описание процедуры (что это, как работает, время),
  - запрещённые формулировки (типа «минералы» для СУВ),
  - УТП центра (если уникальный для услуги),
- [ ] CTA — общий, не дублировать.

### 3.3. Промпты agent2

- [ ] Обязательные блоки в бриф: Проблема, Показания, Противопоказания, Результат, Структура, FAQ

### 3.4. Промпты agent3

- [ ] Целевой порядок H2 прописан (или уже общий в `service_page.md`)
- [ ] Инструкции для «С какими проблемами», «Как проходит», «FAQ»
- [ ] Специфика процедуры: длительность, шаги, типичные вопросы

### 3.5. Шаблон страницы

- [ ] `prompts/templates/service_page.md` — все обязательные блоки в шаблоне

### 3.6. Прогон и проверка

- [ ] agent1 → agent2 → agent3 → agent4
- [ ] Все 7 H2 на месте, FAQ отвечает на типичные вопросы, CTA корректный
