# Пример отчёта checker (Углекислая ванна)

Это пример вывода первого агента. Используй его для теста executor:
```
python seo-agents/agent_checker_executor/agent_checker_executor.py -s "Углекислая ванна" -r output/check_uglekislaya_example.md -o output/tz_uglekislaya_example.md
```

---

## 1. Таблица блоков

| Блок | Статус | Комментарий |
|------|--------|-------------|
| Hero | частично | H1 и подзаголовок есть, но нет маркеров-фактов (длительность, курс). Одна кнопка — не хватает «Задать вопрос». |
| Для кого эта услуга | частично | Есть абзац «Кому особенно нужна СУВ» в тексте, но нет отдельного блока с карточками. Сегменты ЦА размазаны в общем описании. |
| Что даёт услуга | есть | 6 пунктов с ✅, конкретные эффекты. |
| Как проходит процедура | есть | 3 шага (консультация, процедура, после). Можно усилить — добавить нумерацию, время каждого этапа. |
| Результаты курса | есть | 4 пункта. Выполнено. |
| Показания и противопоказания | есть | Два списка, чётко. |
| Стоимость | есть | Таблица с ценой за 1 и за 10 сеансов. Нет примечания об изменении цен. |
| Почему именно наш центр | есть | Таблица сравнения «Энтузиаст» vs «Аналоги». Хорошо. |
| FAQ | есть | 4 вопроса. Можно добавить ещё 1–2 по типичным страхам (гипертония, длительность курса). |
| Связанные услуги | есть | Блок «С этой услугой сочетаются» — карточки. |
| Финальный CTA | частично | Есть призыв «Записаться», но нет второй кнопки «Получить консультацию». |

## 2. Рекомендации по доработке

1. **Hero:** добавить 2–3 маркера-факта (например: «20–25 мин», «Курс 8–12 сеансов», «Безопасно при гипертонии») и вторую кнопку «Задать вопрос».
2. **Для кого:** оформить отдельным блоком с 3–4 карточками (сегмент ЦА + короткое описание). Сейчас информация есть в тексте, но не выделена визуально.
3. **Как проходит:** переверстать в нумерованные шаги с заголовком каждого этапа и временем.
4. **Стоимость:** добавить мелким текстом примечание «Цены могут измениться. Актуальную стоимость уточняйте при записи».
5. **FAQ:** добавить 1–2 вопроса: «Можно ли при диабете?», «Сколько длится эффект после курса?».
6. **Финальный CTA:** добавить вторую кнопку «Получить консультацию» рядом с «Записаться».
